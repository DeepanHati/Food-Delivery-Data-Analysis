# 🍔 Food Delivery Data Analysis

## 📊 End-to-End Data Analytics Project using Python, Pandas, NumPy, Excel & Power BI

An end-to-end data analytics project focused on analyzing food delivery operations, customer behavior, restaurant performance, delivery efficiency, and financial performance.

The project starts with a raw Excel dataset, performs data cleaning and feature engineering using Python, conducts numerical and business analysis using NumPy and Pandas, and finally presents the results through an interactive five-page Power BI dashboard.

---

## 📌 Project Overview

The objective of this project is to transform raw food delivery data into meaningful business insights that can support operational and business decision-making.

The analysis covers:

- Revenue and order performance
- Restaurant performance
- Customer behavior
- Delivery efficiency
- Payment methods
- Customer ratings
- Discounts
- Delivery charges
- Estimated profit
- Monthly revenue trends
- Weekday performance

The project demonstrates an end-to-end data analytics workflow from **raw data to business dashboard**.

---

## 🎯 Business Objectives

The key objectives of this project are:

1. Analyze overall revenue and order performance.
2. Identify top-performing restaurants.
3. Analyze customer ordering behavior.
4. Understand payment method preferences.
5. Evaluate delivery efficiency.
6. Analyze customer ratings.
7. Identify monthly revenue trends.
8. Analyze discounts and delivery charges.
9. Estimate profit using an assumed profit margin.
10. Build an interactive Power BI dashboard for business reporting.
